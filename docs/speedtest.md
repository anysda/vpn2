# Замер скорости через туннель

## BBR и Brutal на Hysteria2

Hysteria2 между entry-нодой и экзитами по умолчанию использует BBR. Для
сравнения с Brutal задайте у нужного элемента `exits` в `config.yaml` обе
скорости: `hy2_up_mbps` (экзит → entry) и `hy2_down_mbps` (entry → экзит),
в целых Мбит/с по измеренной ёмкости своего пути. Применить:
`./deploy.sh 10-foreign <тег>`, затем `./deploy.sh 20-ru-router ru`. Для
возврата на BBR удалите оба поля и повторите стадии. Настройка затрагивает
direct и WARP выбранного экзита; служебный hy2-mgmt остаётся на BBR.
Скорости задаются на соединение, это не общий ограничитель канала экзита.
Критерий в пользу Brutal - прирост от 20 % при потерях 1-3 % без ухудшения
задержки под нагрузкой.

## speedtest.py

`infra/tools/speedtest.py` снимает на стенде одну таблицу: iperf3 TCP (1 и 8
потоков в обе стороны) и UDP через туннель клиент → entry → экзит → сервер,
TTFB HTTPS к зарубежным и российским сайтам, пачку DNS-запросов к AdGuard и
приросты счётчиков узлов (`UdpRcvbufErrors`, ретрансмиты, `tc -s qdisc`,
ЦПУ). Прогоняет все экзиты из `config.yaml`, переключая клиентам
`preferredExit` через панель. Нагрузочный замер - только на стенде.

Что нужно заранее:

- ssh по ключу (через ssh-agent) на entry и в каждую машину-клиент; на
  экзиты скрипт ходит через entry;
- машина за экзитом с `iperf3 -s` на портах 5201, 5202, … (по порту на
  клиента);
- клиенты - по машине на протокол (WireGuard, OpenVPN, IKEv2) с поднятым
  туннелем и DNS туннеля; у каждого свой клиент в панели; на них стоят
  `iperf3`, `curl`, `ping`, `python3`.

```bash
infra/tools/speedtest.py --hub root@<entry> --iperf <iperf-сервер> \
  --client wg=root@<клиент-wg>/<имя-в-панели> \
  --client ovpn=root@<клиент-ovpn>/<имя-в-панели> \
  --client ikev2=root@<клиент-ikev2>/<имя-в-панели> \
  --out before.json > before.md
# после правки - тот же запуск с --out after.json, затем:
infra/tools/speedtest.py --compare before.json after.json
```

Путь до iperf-сервера проседает на минуты целиком, поэтому прогон идёт
кругами (`--repeat`, по умолчанию 5): каждый круг проходит все экзиты и всех
клиентов, в таблицу идёт медиана по кругам. Полный прогон трёх клиентов по
трём экзитам идёт около 45 минут.
