# AdGuard Home

DNS с блок-листом для VPN-клиентов, у которых включена фильтрация
(задаётся при создании клиента и потом не меняется). Управление - во вкладке
«DNS» панели. Веб-интерфейс AdGuard наружу не открыт: слушает только
`127.0.0.1` на entry-ноде.

Прямой вход через SSH-туннель к локальному порту: логин `admin.user`, пароль
- содержимое `/etc/anysda/adguard-password.txt` на entry (только root). Если
установочный пароль панели длиннее 72 байт UTF-8, AdGuard получает
64-символьный SHA-256 от `vpn2-adguard-v1`, нулевого байта и полного пароля;
короткие пароли остаются прежними. Деплой и restore заново согласуют эту
учётку с панелью; смена пароля в профиле панели установочную учётку AdGuard
не меняет.

Лимиты памяти и срок хранения журнала - `entry_resources.agh_*`,
`retention_days`, `querylog_size` в `config.yaml`.
